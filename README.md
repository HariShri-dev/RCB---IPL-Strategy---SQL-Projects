# RCB Team Analysis using SQL

## Project Overview
This project analyzes Royal Challengers Bangalore (RCB) team performance using SQL queries and relational database concepts.

## Objectives
- Analyze player performance
- Compare batting statistics
- Evaluate bowling efficiency
- Identify top performers
- Study match outcomes

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- HAVING
- JOINS
- Subqueries
- Aggregate Functions
- CASE Statements

## Tools Used
- MySQL
- SQL Workbench

## Key Insights
- Top scoring batsmen identified
- Best economy bowlers analyzed
- Win/loss trends studied
